# Khus HSE Client — Web

Неофициальный веб-клиент HSE App X (SwiftUI-версия — в приватном репозитории автора).
Один статический `index.html`: вход OAuth2/PKCE через ВШЭ, расписание, оценки, поиск,
дедлайны, уведомления, столовые, профиль. Бэкенд не нужен (API и Keycloak отдают CORS).
